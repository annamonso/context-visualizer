\begin{abstract}
Applications built on large language models (LLMs) are becoming
multi-agent and are moving onto clusters, yet to our knowledge no
existing observability tool covers both facts at once: LLM-observability platforms capture rich
agent semantics but have no notion of physical topology, while HPC and
fleet monitoring knows node health at scale but nothing about agents. This
thesis fills that gap, starting from one observation: a multi-agent
execution is already a causally-ordered event log, so a distributed shared
log is its natural storage substrate. We state the minimal contract such a
substrate must honour, five features (caller-named, ordered, durable,
replayable, multi-reader streams) that any log store satisfying them can
host the system, and four further features whose absence costs a specific,
named mechanism rather than a redesign. Against that contract we design
\sys{}, a drop-in observability system for LLM-agent fleets, and implement
it on ChronoLog, a distributed tiered log store that additionally places a
capture process on every cluster node and so makes host attribution
structural. Two capture paths feed the log (LLM turns through a
spooled capture worker; inter-agent calls through per-node collectors)
with at-least-once capture and effectively exactly-once ingest, and a
hot/cold read design works around the log's ingest-optimized acceptance
window to serve real-time views from the same event stream. On this
substrate we build fleet-scale analyses: failure detection with signature
clustering and zero-cost diagnosis, per-node health rollups whose cost is
independent of event volume, and cross-host critical-path tracing. We
validate the system end-to-end with real Claude agents on live 4- and
8-node ChronoLog clusters (28/28 automated checks, up to 32 concurrent
agents) and measure it throughout: capture costs the agent 3.6\,ms per
turn (statistically invisible against real LLM latency), events
reach the operator's screen in 10.7\,ms against a 20--30\,s durable
drain, fleet queries stay flat as event volume grows $50\times$, and a
ground-truth fault study scores 580/580 detections with zero false
positives. In a timed case study, a first-time operator produced a
complete, verified cross-layer diagnosis through the system in 72
seconds, a task they could not begin from raw logs.
\end{abstract}
